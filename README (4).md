# ALPHA ANALYZER V16 — Spoken Trade Alerts

The previous beep alert has been replaced with a spoken browser notification.

Example:
"New trade alert. NSE Intraday. ICICIBANK. Buy."

For a sell:
"New trade alert. MCX Intraday. CRUDEOIL. Sell."

The dashboard alert banner and alert history remain unchanged.

Browser must be open and speech playback must be permitted.
