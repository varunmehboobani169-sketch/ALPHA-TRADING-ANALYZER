# ALPHA ANALYZER V18 — 3-Star Trade Ranking

Three-star model:
1. ⭐ P&F — exact 3-column stock pattern:
   >15-box Anchor -> 1–5 box pullback -> 3rd column DTB/DBS.
2. ⭐ OI — futures OI buildup confirms the directional stock pattern.
3. ⭐ Sector — sector/NIFTY synthetic ratio is evaluated using the same P&F philosophy; a confirmed bullish ratio pattern supports BUY, bearish supports SELL.

Trade Ranking page ranks valid bullish/bearish candidates by Star Count (3 to 0), then Anchor size and pullback quality.

The P&F entry remains the stock DTB/DBS. OI and Sector are confirmations/ranking factors.
